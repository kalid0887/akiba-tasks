## 📌 About This Project

This repository contains my completed Week 1 Python programming assignments for the **AKIBA Technologies Software Engineering & Backend Bootcamp**.

The project focuses on building a strong foundation in Python through practical, real-world programming exercises. Each task demonstrates the application of fundamental programming concepts, including variables, data types, user input, type conversion, arithmetic operations, and formatted output.

The repository includes **10 individual programming tasks and one mini-project** that combines the concepts learned throughout the week.

My goal is not only to write working programs but also to understand the logic behind them and develop the problem-solving skills needed to become a professional software engineer.

## 🚀 Mini-Project: Student Profile System

The Student Profile System is the final mini-project for Week 1. It combines the fundamental concepts practiced in the individual assignments.

### Features

* Collects the student's full name and age.
* Records the student ID and city.
* Captures university and department information.
* Collects email address and phone number.
* Records the favorite programming language.
* Displays the student's programming goal.
* Presents the collected information in a clean, professional format.

## ⚙️ How to Run the Programs

### Prerequisites

Make sure Python 3 is installed on your computer.

Check your installation with:

```bash
python3 --version
```

### 1. Clone the repository

```bash
git clone https://github.com/kalid0887/akiba-week1-python.git
```

### 2. Enter the project directory

```bash
cd akiba-week1-python
```

### 3. Run an individual task

For example, to run the Personal Introduction program:

```bash
python3 task01_personal_introduction.py
```

To run the Student Profile System:

```bash
python3 mini_project/student_profile.py
```

**Note:** Each program runs independently and may ask you to enter information in the terminal.
